# Resume-Code
A curated collection of my work as an aspiring Data Science practitioner. Creating automated pipelines and predictive models (Python/Scikit-Learn) to analyze intricate datasets, including NYC weather-driven retail growth, US election demographics, and GIS historical mapping.

**NYC Weather & Retail Impact Analysis
Code and Files:** Inside the NYC Weather and Retail Impact Analysis Zip folder

**Key Skills:** Time-series forecasting, Scikit-Learn (Linear Regression), Data Engineering (84k+ rows).

**The Insight:** Developed a model with 99% accuracy ($R^2=0.99$) to predict NYC temperatures using regional "scout" data, then correlated "high-friction" weather days to fluctuations in monthly retail growth.


**Object Detection with YOLOv8 and Real-Time Video Analysis**
**Code and Files:** Inside the Object Detection with YOLOv8 and Real-Time Video Analysis zip folder

**Key Skills:** Real-Time Instance Segmentation (YOLOv8 Nano), Computer Vision & Video Analytics (OpenCV, VidGear, yt-dlp), Multi-Object Kinetic Tracking (ByteTrack, NumPy Centroid Calculations).

**The Insight:** Constructed a low-latency, real-time sports analytics pipeline that streams live YouTube footage and isolates high-speed objects like baseball bats via COCO class filtering. Optimized real-time performance by calibrating confidence thresholds (down to 0.15) to mitigate high-velocity motion blur while dynamically computing the object's geometric center of mass across consecutive frames.
